A companion to [Pathfinder](/projects/pathfinder/) that slows everything down. It walks through A* search and Dijkstra's algorithm one step at a time and shows the values each algorithm is working with in every cell.

## Features

- Supports A* search and Dijkstra's algorithm
- Written in Python with a Tkinter GUI
- Step through the algorithm one move at a time
- Each cell shows
  - the direction of the shortest route back
  - the step count
  - the value of the heuristic function
  - the total cost of the cell

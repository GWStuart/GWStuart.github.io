Bézier curves are smooth curves, defined by a series of control points, that are used throughout computer graphics. In this program you place the points, and it animates how the curve is constructed from them by repeated linear interpolation.

## Features

- Visualises Bézier curves of any degree
- Slow down, pause and rewind the animation

K-means is an unsupervised machine learning algorithm that groups data into k clusters, each defined by a centroid. This program shows the algorithm one step at a time: assigning each point to its nearest centroid, then moving each centroid to the centre of its points, until nothing changes.

## Features

- Unsupervised clustering of two-dimensional data into k groups
- Clearly shows each step of the process

A multi-purpose physics engine that uses Verlet integration to simulate everything from free particles to cloth. Simulations can be interacted with in real time.

## Features

- Simulates many phenomena, including
  - particle physics
  - pendulums
  - soft-body structures
  - cloth physics
- Responsive GUI that supports live resizing
- Interact with the simulated environment in real time

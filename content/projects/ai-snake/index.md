A program for building, testing and rendering AI players for the game Snake. Different AI models plug into the same game, and finished games can be rendered to video.

## Features

- Modular design that supports multiple different AI models
- Renders high-quality games to MP4 video using OpenCV
- Supports variable board sizes
- Simple command-line interface for testing and rendering games

Wolfensterminal is a first-person raycaster in the style of the original Wolfenstein 3D, written in C and drawn entirely with terminal characters. Players can join the same map over the network through a small UDP server.

It was awarded best overall runner-up at the 2025 UQ Hackathon, winning a $1000 prize.

## Features

- Runs entirely inside a terminal
- 3D graphics using raycasting
- Multiplayer support through a UDP network server
- Textures and sprites that are applied and scaled dynamically
- A basic map editor

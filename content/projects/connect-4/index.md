An AI opponent you can play Connect 4 against. It uses the minimax algorithm to search up to 7 moves into the future before choosing where to play.

## Features

- Implementation of the minimax algorithm
- Looks up to 7 moves ahead
- Written in Python with Pygame for the GUI

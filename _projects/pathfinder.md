The project is set in a grid-tiled environment where users are able to select start/end points and draw in obstacles that the pathfinder must overcome. The pathfinding process is then animated showing visiaully each cell that is being checked by the program giving an intution for how the alorithms work.
<br>
<br>
In this project I implemented two of the most common pathfinding algorithms: A* search and Dijkstra's algorithm. By toggling between the two users can clearly see the differences in the behaviour of each algorithm."
